# PlantUML Diagrams

PlantUML is a tool for generating various types of diagrams from textual representations. The syntax for class diagrams can be found [here](https://plantuml.com/class-diagram).

To preview diagrams, press `Alt + D` in the VSCode devcontainer or use the [PlantUML online server](https://www.plantuml.com/plantuml/uml/).
